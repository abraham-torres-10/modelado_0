**PŔACTICA 5**

*Reflexión final*

En esta práctica, al momento de agregar una prueba nueva, cada que falla nos veíamos obligados a cambiar el código para que lograra que las pruebas pasarán en verde. Y ejecutando todas las pruebas después de cada cambio, comprobamos que el último cambio no hubiera afectado el funcionamiento. La parte más complicada fue la etapa de refactorización, pues reestructurar el diseño y optimizar el código pide encontrar soluciones más limpias sin romper el comportamiento ya validado por las pruebas.
