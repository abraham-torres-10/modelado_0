**PŔACTICA 5**

*Reflexión final*

En esta práctica, al momento de agregar una prueba nueva, cada que falla nos veíamos obligados a cambiar el código para que lograra que las pruebas pasarán en verde. Y ejecutando todas las pruebas después de cada cambio, comprobamos que el último cambio no hubiera afectado el funcionamiento. La parte más difícil fue la refactorización, ya que es pensar una manera de optimizar nuestro código, sin provocar fallas.
